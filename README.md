# **Risk Analysis - Notebooks for the Tutorials**

This repository contains the programming part of the tutorials for the course **_Risk Analysis_** offered by Prof. Daniel Straub.  It provides jupyter notebooks and coresponding resources and is meant to introduce you to the computational side of risk analysis. 

The noteboooks are meant to support your understanding of risk analysis concepts. They complement the tutorials provided in Moodle. We prepare these notebooks before the class to get you started on experimenting on your own. However, in the exam, programming will play a minor role so focus on understanding the concepts taught in class and make sure that you are able solve them by hand.


## 🚀 **Getting Started**

We are using **🐍 Python** for the tutorials.  
To make this easier for you, we provide **Google Colab notebooks** ☁️, which allow you to run Python code directly in your browser — **no installation needed**.

However, you’re free to use any programming language or environment you prefer, though our support will focus on Python.

> 💡 **Note:** To use Colab, you need a **Google account**.  
> If you don’t have one, we recommend installing **[Anaconda](https://www.anaconda.com/download)** — it includes everything you need to start with Python and run notebooks locally.  
> After the Anaconda installation you can either just download the whole repository. However, we will update this every week. If you want to avoid downloading the whole thing all the time you can use [git](git_for_anaconda.md). 
> To open the notebooks use jupyter in Anaconda.
> 🗨️ Need help? Reach out in the *Moodle forum*.
